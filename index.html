How to use
  • Tap/click a piece to see legal destinations.
  • Legal moves appear as arrows: green for a move, red for a capture (blue for the lesson's book move).
  • Create a position: pick that mode, place pieces, choose the side to move, then press Start playing and move both sides. Edit position brings the editor back.
  • The last move is shaded yellow and a king in check glows red.
  • Back undoes a move (a full turn against the computer); Flip turns the board around.
  • When a pawn reaches the last rank, choose a promotion piece.
  • Checkmate, stalemate and automatic draws are detected; threefold repetition and the 50-move rule can be claimed with Claim draw.
  • Keyboard: ← = Back, Esc = deselect.

Pieces use built-in Unicode chess symbols, so they work offline. If your system font lacks a glyph, try a browser/system font that includes chess symbols.
